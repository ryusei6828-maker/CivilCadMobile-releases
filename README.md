# CivilCad Mobile (Android)

図面 (DXF・SFC・JWW・DWG) と PDF を、スマートフォンで見る・測る・実測値を書き込むアプリです。
ここは配布用です。ソースは置いていません。

**準備中です。最初の版はまだ出ていません。**

## 入れ方

1. 下のリンクを Android で開く (QR コードでも可)
   https://github.com/ryusei6828-maker/CivilCadMobile-releases/releases/latest
2. APK をダウンロードする
3. 「提供元不明のアプリ」の許可を求められたら許可する
4. インストールする

更新はアプリが知らせます。上書きで入り、設定は残ります。

## 安全について

- 図面は端末の外へ送りません。ネットは新しい版の確認にだけ使います (設定で切れます)。
- 各リリースに APK の SHA-256 を書いています。ここ以外から入手した APK は使わないでください。
